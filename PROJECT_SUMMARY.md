## 🎯 Реализованные функции

### ✅ Основной функционал

1. **Поиск погоды по городу**
   - Геокодирование через Nominatim API (OpenStreetMap)
   - Поддержка городов на любом языке
   - Обработка неизвестных городов

2. **Отображение текущей погоды**
   - Температура (°C)
   - Ощущаемая температура
   - Скорость ветра (км/ч)
   - Направление ветра (С, СВ, В, ЮВ, Ю, ЮЗ, З, СЗ)
   - Влажность (%)
   - Погодные условия с иконками

3. **Прогноз на 7 дней**
   - Максимальная и минимальная температура
   - Погодные условия
   - Осадки (если есть)
   - Скорость ветра
   - Визуальные иконки погоды

4. **Отображение информации**
   - Название города
   - Текущая дата и время
   - Все данные отформатированы на русском языке

5. **История поисков**
   - Сохранение в SQLite базу данных
   - Отображение последних 10 поисков
   - Быстрый повторный поиск по клику

## 🗄️ Структура базы данных

```sql
CREATE TABLE search_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    city_name TEXT NOT NULL,
    country TEXT,
    latitude REAL NOT NULL,
    longitude REAL NOT NULL,
    temperature REAL,
    weather_code INTEGER,
    search_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_search_date ON search_history(search_date DESC);
```

**Функции:**
- Сохранение каждого поиска
- Хранение координат для быстрого повторного запроса
- Сортировка по дате (новые первыми)
- Лимит отображения: 10 последних записей

## 🔌 API Endpoints

### GET /api/geocode
**Описание:** Получение координат города по названию

**Query параметры:**
- `city` (string, required) - название города

**Ответ (200):**
```json
{
  "name": "Москва",
  "latitude": 55.7558,
  "longitude": 37.6173,
  "country": "Россия"
}
```

**Ошибки:**
- 400 - Название города не указано
- 404 - Город не найден
- 500 - Ошибка геокодирования

---

### GET /api/weather
**Описание:** Получение данных о погоде по координатам

**Query параметры:**
- `latitude` (number, required) - широта
- `longitude` (number, required) - долгота

**Ответ (200):**
```json
{
  "current": {
    "temperature_2m": 15.2,
    "apparent_temperature": 13.5,
    "relative_humidity_2m": 65,
    "weather_code": 0,
    "wind_speed_10m": 12.5,
    "wind_direction_10m": 180
  },
  "daily": {
    "time": ["2026-10-17", "2026-10-18", ...],
    "temperature_2m_max": [18, 20, ...],
    "temperature_2m_min": [10, 12, ...],
    "weather_code": [1, 2, ...],
    "precipitation_sum": [0, 2.5, ...],
    "wind_speed_10m_max": [15, 18, ...]
  }
}
```

**Ошибки:**
- 400 - Координаты не указаны
- 500 - Ошибка получения погоды

---

### POST /api/history
**Описание:** Сохранение поиска в историю

**Body (JSON):**
```json
{
  "city_name": "Москва",
  "country": "Россия",
  "latitude": 55.7558,
  "longitude": 37.6173,
  "temperature": 15.2,
  "weather_code": 0
}
```

**Ответ (200):**
```json
{
  "success": true,
  "id": 1
}
```

---

### GET /api/history
**Описание:** Получение истории поисков (последние 10)

**Ответ (200):**
```json
[
  {
    "id": 1,
    "city_name": "Москва",
    "country": "Россия",
    "latitude": 55.7558,
    "longitude": 37.6173,
    "temperature": 15.2,
    "weather_code": 0,
    "search_date": "2026-10-17T12:00:00.000Z"
  }
]
```

## 🔒 Безопасность

### ✅ Реализовано
1. **SQL Injection защита** - prepared statements в SQLite
2. **XSS защита** - использование textContent вместо innerHTML
3. **Валидация входных данных** - на backend и frontend
4. **.gitignore** - исключение .env, node_modules, *.db
5. **Обработка ошибок** - без раскрытия внутренних деталей
6. **User-Agent** - корректный заголовок для Nominatim API

### ℹ️ Замечания
- API не требует ключей (бесплатные публичные сервисы)
- Нет аутентификации (не требуется для данного проекта)
- Rate limiting реализован на стороне API провайдеров
