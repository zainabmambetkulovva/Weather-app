# 🌤️ Weather App - Приложение для прогноза погоды

Современное веб-приложение для получения актуальной информации о погоде в любом городе мира с прогнозом на 7 дней.

## 🎯 Особенности

- **Поиск по городу**: Введите название любого города и получите актуальную информацию о погоде
- **Текущая погода**: Температура, ощущаемая температура, влажность, скорость и направление ветра
- **Прогноз на 7 дней**: Подробный прогноз погоды на неделю вперёд
- **Иконки погодных условий**: Визуальное отображение текущих погодных условий
- **История поисков**: Сохранение и быстрый доступ к ранее искомым городам
- **Обработка ошибок**: Корректная обработка неизвестных городов, ошибок API и проблем с интернетом
- **Адаптивный дизайн**: Отличное отображение на компьютерах, планшетах и смартфонах
- **Индикатор загрузки**: Визуальная обратная связь при загрузке данных

## 🛠️ Технологии

### Frontend
- **HTML5** - структура приложения
- **CSS3** - современный адаптивный дизайн с анимациями и градиентами
- **JavaScript (Vanilla)** - логика приложения без дополнительных библиотек

### Backend
- **Node.js** - серверная платформа
- **Express.js** - веб-фреймворк для создания API
- **sql.js** - встраиваемая SQL база данных для хранения истории (SQLite на JavaScript, не требует компиляции)

### API
- **Open-Meteo API** - бесплатный API для получения данных о погоде (не требует регистрации)
- **Nominatim API (OpenStreetMap)** - бесплатный геокодирующий сервис для определения координат городов

## 📦 Установка

### Требования
- Node.js версии 14.0 или выше
- npm (устанавливается вместе с Node.js)

### Шаги установки

1. **Клонируйте репозиторий**:
```bash
git clone https://github.com/zainabmambetkulovva/Weather-app.git
cd Weather-app
```

2. **Установите зависимости**:
```bash
npm install
```

3. **Создайте файл .env** (опционально):
```bash
cp .env.example .env
```

В файле `.env` можно настроить:
- `PORT=3000` - порт сервера (по умолчанию 3000)
- `DATABASE_PATH=./database/weather.db` - путь к базе данных

4. **Инициализируйте базу данных**:
База данных автоматически создаётся при первом запуске сервера. Или можно выполнить:
```bash
npm run init-db
```

## 🚀 Запуск

Запустите сервер:
```bash
npm start
```

Приложение будет доступно по адресу: **http://localhost:3000**

## 📖 Использование

1. Откройте приложение в браузере
2. Введите название города в поле поиска (например, "Москва", "Paris", "Tokyo")
3. Нажмите кнопку "Поиск" или клавишу Enter
4. Приложение отобразит:
   - Текущую погоду с подробными параметрами
   - Прогноз на следующие 7 дней
   - Город сохранится в историю поисков

### История поисков
- Последние 10 поисков сохраняются в базе данных
- Кликните на любой элемент истории для быстрого поиска

## 🔌 API Endpoints

### GET `/api/geocode`
Получение координат города по названию

**Параметры запроса:**
- `city` (обязательный) - название города

**Ответ:**
```json
{
  "name": "Москва",
  "latitude": 55.7558,
  "longitude": 37.6173,
  "country": "Россия"
}
```

### GET `/api/weather`
Получение данных о погоде по координатам

**Параметры запроса:**
- `latitude` (обязательный) - широта
- `longitude` (обязательный) - долгота

**Ответ:**
```json
{
  "current": {
    "temperature_2m": 15.2,
    "apparent_temperature": 13.5,
    "relative_humidity_2m": 65,
    "weather_code": 0,
    "wind_speed_10m": 12.5,
    "wind_direction_10m": 180
  },
  "daily": {
    "time": ["2026-10-17", "2026-10-18", ...],
    "temperature_2m_max": [18, 20, ...],
    "temperature_2m_min": [10, 12, ...],
    "weather_code": [1, 2, ...],
    "precipitation_sum": [0, 2.5, ...],
    "wind_speed_10m_max": [15, 18, ...]
  }
}
```

### POST `/api/history`
Сохранение поиска в историю

**Тело запроса:**
```json
{
  "city_name": "Москва",
  "country": "Россия",
  "latitude": 55.7558,
  "longitude": 37.6173,
  "temperature": 15.2,
  "weather_code": 0
}
```

### GET `/api/history`
Получение истории поисков (последние 10)

**Ответ:**
```json
[
  {
    "id": 1,
    "city_name": "Москва",
    "country": "Россия",
    "latitude": 55.7558,
    "longitude": 37.6173,
    "temperature": 15.2,
    "weather_code": 0,
    "search_date": "2026-10-17T12:00:00.000Z"
  }
]
```

## 🌐 Используемые API

### Open-Meteo API
- **URL**: https://api.open-meteo.com
- **Документация**: https://open-meteo.com/en/docs
- **Особенности**:
  - Бесплатный доступ без регистрации
  - Не требует API ключа
  - Предоставляет прогноз погоды до 16 дней
  - Поддержка различных метеорологических параметров
  - Лимит: до 10,000 запросов в день

### Nominatim API (OpenStreetMap)
- **URL**: https://nominatim.openstreetmap.org
- **Документация**: https://nominatim.org/release-docs/develop/api/Search/
- **Особенности**:
  - Бесплатный геокодирующий сервис
  - Не требует API ключа
  - Требует указание User-Agent в заголовках
  - Лимит: максимум 1 запрос в секунду
  - Рекомендуется использовать для некоммерческих проектов

## ⚠️ Обработка ошибок

Приложение корректно обрабатывает следующие ситуации:

1. **Неизвестный город**: Отображается сообщение "Город не найден"
2. **Отсутствие интернета**: Отображается сообщение "Нет подключения к интернету"
3. **Ошибки API**: Отображаются понятные сообщения об ошибках
4. **Пустой запрос**: Требование ввести название города
5. **Ошибки сервера**: Логирование в консоль и информативные сообщения пользователю

## 🐛 Устранение неполадок

### Порт уже занят
Измените порт в файле `.env`:
```
PORT=3001
```

### База данных не создаётся
Убедитесь, что папка `database/` существует и есть права на запись:
```bash
mkdir database
npm run init-db
```

### Ошибка при установке better-sqlite3
Убедитесь, что установлены build tools:

**Windows:**
```bash
npm install --global windows-build-tools
```

**Linux/Mac:**
```bash
# Обычно build tools уже установлены
```
