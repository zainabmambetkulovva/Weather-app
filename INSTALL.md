# 📥 Инструкция по установке и запуску Weather App

## Шаг 1: Установка зависимостей

Откройте терминал в корневой папке проекта и выполните:

```bash
npm install
```

Это установит следующие зависимости:
- **express** - веб-сервер
- **sql.js** - база данных SQLite (чистый JavaScript, не требует компиляции)
- **dotenv** - управление переменными окружения

## Шаг 2: Создание файла .env (опционально)

Скопируйте `.env.example` в `.env`:

```bash
copy .env.example .env
```

Или создайте вручную файл `.env` с содержимым:
```
PORT=3000
DATABASE_PATH=./database/weather.db
```

## Шаг 3: Запуск приложения

```bash
npm start
```

## Шаг 4: Открытие в браузере

Откройте в браузере:
```
http://localhost:3000
```

## Проверка работоспособности

1. Введите название города (например, "Москва", "London", "Paris")
2. Нажмите кнопку "Поиск" или Enter
3. Должна отобразиться информация о погоде:
   - Текущая температура и погодные условия
   - Ощущаемая температура
   - Скорость и направление ветра
   - Влажность
   - Прогноз на 7 дней

## Возможные проблемы

### Порт 3000 занят
Измените порт в `.env`:
```
PORT=3001
```

### Ошибка при установке better-sqlite3
На Windows может потребоваться установка build tools:
```bash
npm install --global windows-build-tools
```

**Решение:** В проекте используется `sql.js` вместо `better-sqlite3`, поэтому компиляция не требуется. Библиотека полностью на JavaScript и устанавливается без проблем на любой системе.

### База данных не создаётся
База создаётся автоматически при первом запуске. Если возникли проблемы:
```bash
npm run init-db
```

## Тестирование функций

### Тест 1: Успешный поиск
- Введите: "Москва"
- Ожидается: карточка с погодой, температура, прогноз на 7 дней

### Тест 2: Неизвестный город
- Введите: "asdfghjkl123"
- Ожидается: красное сообщение "Город не найден"

### Тест 3: Пустой запрос
- Оставьте поле пустым и нажмите "Поиск"
- Ожидается: сообщение "Пожалуйста, введите название города"

### Тест 4: История поисков
- Найдите несколько городов
- Прокрутите вниз до секции "История поисков"
- Кликните на любой город из истории
- Ожидается: повторный поиск этого города

### Тест 5: Адаптивность
- Измените размер окна браузера
- Откройте на мобильном устройстве
- Ожидается: корректное отображение на всех размерах экрана

## Структура базы данных

После первого запуска создаётся файл `database/weather.db` со следующей структурой:

```sql
CREATE TABLE search_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    city_name TEXT NOT NULL,
    country TEXT,
    latitude REAL NOT NULL,
    longitude REAL NOT NULL,
    temperature REAL,
    weather_code INTEGER,
    search_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

Можно просмотреть содержимое базы любым SQLite клиентом или через командную строку:
```bash
sqlite3 database/weather.db "SELECT * FROM search_history;"
```
